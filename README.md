# FreeAI Hub

A lightweight, provider-neutral dashboard for using AI models through legitimate free tiers and local runtimes.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Current scope

- Provider status dashboard and model routing preferences.
- Clear separation between free-tier access, local models, and paid APIs.
- Local-only settings storage in the browser.
- Setup guidance for providers and local runtimes.

## Important

This app does not bypass provider quotas, account limits, or payment requirements. GPT and Claude are only available where the user has valid authorized access; free access is not guaranteed. Never paste API keys into this static demo. Secure server-side credential storage and real provider adapters must be implemented before connecting live APIs.
